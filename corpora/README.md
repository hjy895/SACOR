# Parallel Corpora

This directory contains the parallel corpora for all eight South Asian languages.

Each corpus file is a TSV file with the following structure:
- Column 1: English sentence
- Column 2: Target language sentence
- Additional columns: metadata (variety, region, translator, etc.)

## Files

- `en-pan.tsv` - English-Punjabi parallel corpus
- `en-pbt.tsv` - English-Pashto parallel corpus
- `en-snd.tsv` - English-Sindhi parallel corpus
- `en-skr.tsv` - English-Saraiki parallel corpus
- `en-urd.tsv` - English-Urdu parallel corpus
- `en-bal.tsv` - English-Balochi parallel corpus
- `en-hnd.tsv` - English-Hindko parallel corpus
- `en-brh.tsv` - English-Brahui parallel corpus
- `multilingual-corpus.tsv` - Cross-lingual aligned multilingual corpus
